# Beautician Site — Project Instructions

## Overview
This is a beautician/salon website for KBS. It consists of a multi-page static site with a homepage, services page, and booking page.

## Tech Stack
- **HTML5** — Semantic markup across `index.html`, `services.html`, and `booking.html`
- **CSS3** — Vanilla CSS in `style.css` (custom properties, gradients, animations)
- **JavaScript** — Vanilla JS in `script.js` (navigation, interactions)

## Project Structure
```
beautician-site/
├── index.html          # Homepage (hero, our story, gallery, team, contact)
├── services.html       # Services listing page
├── booking.html        # Appointment booking page
├── style.css           # Global styles and design tokens
├── script.js           # Client-side interactivity
├── KBS_logo_extracted.png
├── hero_beauty.png
├── service_hair.png
├── gallery_hair.png
├── team_portrait.png
└── [various salon photos]
```

## Design Principles
- Premium, modern aesthetic with rich visuals
- Smooth micro-animations and hover effects
- Responsive layout for all screen sizes
- Dark/elegant color palette befitting a high-end salon

## Key Guidelines
- Maintain the existing design system defined in `style.css` custom properties
- Keep the site fully static (no build tools or frameworks)
- All images are local assets — no external CDN dependencies
- Ensure cross-page navigation consistency across all three pages
